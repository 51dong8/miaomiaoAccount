## 需要手工补充的素材

以下素材需在**真机安装后**截图（建议 1080×2400 分辨率）：

### 应用截图（至少 4 张）
1. **首页**：本月收支总览 + 预算进度卡 + 猫咪状态卡
2. **记一笔**：金额键盘 + 分类选择（体现记账动画）
3. **账单**：按日分组列表（体现复制/编辑入口）
4. **统计**：分类饼图 + 月度趋势
5. （可选）**猫咪系统**：小鱼干/连续天数/成就
6. （可选）**设置**：主题切换、备份导出

### 截图规范
- 背景使用默认浅色主题（温暖奶油色），避免深色截图
- 截图前先在「设置 → 备份」导出一次 CSV 以展示数据完整性
- 每张截图避免露出测试用的敏感备注内容

## 上架信息（建议文案）

- **应用名称**：喵喵记
- **一句话简介**：离线记账 · 预算提醒 · 猫咪陪伴
- **详细描述**：
  > 喵喵记是一款完全离线的猫咪主题记账应用。支持支出/收入、按日账单、自定义分类与账户、月预算与分类预算超支提醒、周期账单自动记账、月收支统计与分类占比，还有会陪伴你的小猫咪——每记一笔赚一条小鱼干，连续记账点亮小火苗。
  >
  > 所有数据仅保存在本地，不上传任何服务器，隐私安全。
- **分类**：财务 / 记账
- **标签**：记账、预算、猫咪、离线
