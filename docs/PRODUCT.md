# 喵喵记 · 产品文档（PRODUCT.md）

## 产品定位
面向个人用户的轻量本地记账 App。核心卖点：**3 秒记一笔 + 猫咪养成正反馈**。
无广告、无云同步、隐私友好——数据 100% 存本机。

## 目标用户
- 想记账但坚持不下来的人（用猫咪激励降低流失）
- 注重隐私、不需要联网功能的用户

## MVP 功能（已实现，v1.0.0）
| 模块 | 内容 | 状态 |
| --- | --- | --- |
| 记一笔 | 支出/收入、金额键盘、分类、账户、日期、备注 | ✅ |
| 账单列表 | 按日分组、日汇总、备注搜索、类型筛选、点击编辑、删除 | ✅ |
| 分类管理 | 内置 12 类 + 自定义（emoji/颜色）、编辑、删除保护 | ✅ |
| 账户管理 | 现金/微信/支付宝/银行卡 + 自定义、归档 | ✅ |
| 统计 | 月收支、分类环形图、分类排行、30 天趋势折线 | ✅ |
| 预算 | 月预算、分类预算、进度条、超支提醒（含每月起始日） | ✅ |
| 猫咪系统 | 记账动画、小鱼干、连续天数、成就、动画开关 | ✅ |
| 设置 | 主题（系统/浅/深）、货币符号、每月起始日、CSV/JSON 导出、JSON 导入恢复 | ✅ |
| 存储 | Room 本地数据库，完全离线可用 | ✅ |

## 非目标（本期不做）
- 云同步、多用户
- OCR / 自动记账 / 多币种 / 余额管理
- 重复账单、分期、报销
- 桌面组件（Glance）、生物识别锁、通知提醒（后续里程碑）

## 验收口径
任何功能必须满足：能编译、能运行、数据能保存、退出重进不丢、空状态正常、关键逻辑有测试、不破坏已有功能。
